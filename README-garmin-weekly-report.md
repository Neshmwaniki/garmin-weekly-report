**Context:** Garmin Connect captures rich activity and health data, but reviewing it week to week by hand is tedious and easy to skip. This project automates the pull-and-summarise loop so a consistent weekly report is generated with no manual effort.

---

## What this project does

- **Pulls** weekly activity/health data from Garmin.
- **Cleans and aggregates** it into the metrics that matter week over week.
- **Generates a weekly report** automatically, on a repeatable schedule.

## Approach

- **Automation over manual effort** — the value is in removing the human step so the report appears reliably every week.
- **Reproducibility** — the same code produces the same report each run, which is what makes recurring reporting trustworthy.

## Why this is a useful work sample

- **Reproducible, automated reporting** — the exact discipline that keeps recurring M&E dashboards and program reports reliable instead of drifting.
- **End-to-end thinking** — data source → transformation → scheduled, formatted output.
- **Operational reliability** — recurring deliverables are a different skill from one-off analysis, and this demonstrates it.
